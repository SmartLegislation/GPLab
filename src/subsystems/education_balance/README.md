# 教育资源平衡子系统 (Education Balance Subsystem)

## 概述

教育资源平衡子系统模拟教育政策对学校质量分布、学生选择行为和社会流动性的影响。该子系统包含两个核心组件，共同模拟教育资源配置和学校选择的复杂动态。

## 系统组件

### 1. 教育资源系统 (EducationResourceSystem)

**核心功能：**
- 管理不同层次学校的质量分布（顶级、优质、普通、薄弱）
- 跟踪学生学业成就和社会经济流动性
- 实施教育政策对学校质量的影响
- 处理学校转学申请和成功率

**关键机制：**
- **学校质量动态调整**：根据政策投入调整各类学校的教育质量
- **学生成就评估**：基于学校质量和个人能力计算学生成就
- **社会流动性追踪**：监测教育对社会阶层流动的影响
- **转学机制**：处理学生的转学申请和录取过程

### 2. 学校选择系统 (SchoolChoiceSystem)

**核心功能：**
- 模拟家庭的学区选择和居住决策
- 管理学区房价与学校质量的关联
- 跟踪居住迁移和选择动机
- 评估住房可负担性对教育选择的影响

**关键机制：**
- **学区房价动态**：学校质量与房价的相关性调整
- **居住选择决策**：基于经济能力和教育偏好的迁移决策
- **可负担性分析**：评估不同收入群体的教育选择约束
- **满意度追踪**：监测家庭对学校选择的满意程度

## 运作流程

### 初始化阶段
1. **学校质量设定**：建立四个层次的学校质量基准
2. **代理分配**：根据社会经济背景将代理分配到不同学区
3. **房价初始化**：设定各学区的相对房价水平
4. **基础设施质量**：初始化各类学校的设施条件

### 仿真步骤
1. **政策更新**：应用当前教育政策对学校质量的影响
2. **代理决策处理**：
   - 处理转学申请
   - 处理居住迁移决策
   - 更新教育投资决策
3. **系统状态更新**：
   - 调整学校质量分布
   - 更新房价水平
   - 计算学生成就变化
4. **跨系统通信**：通过黑板模式共享市场状态信息

### 评估指标

**教育公平性指标：**
- 不同社会经济背景学生的成就差距
- 优质教育资源的分布均衡度
- 社会流动性指数

**政策效果指标：**
- 薄弱学校质量提升幅度
- 转学成功率变化
- 整体教育质量改善

**市场动态指标：**
- 学区房价波动
- 居住迁移频率
- 住房可负担性指数

## 代理交互

### 输入信息
代理接收以下系统信息进行决策：
- 当前就读学校类型和质量
- 可申请的学校选项和录取概率
- 各学区房价和可负担性
- 教育政策变化信息
- 同龄人成就水平

### 决策选项
代理可以做出以下决策：
- **转学申请**：申请转入更好的学校
- **居住迁移**：搬迁到更好的学区
- **教育投资**：增加课外教育支出
- **满意度反馈**：对当前教育状况的评价

### 约束条件
- **经济约束**：收入水平限制居住和教育选择
- **政策约束**：学区政策和转学规定
- **能力约束**：学生学业能力影响录取概率
- **社会约束**：社会网络和信息获取能力

## 政策建模

### 支持的政策类型
1. **资源均衡政策**：向薄弱学校增加投入
2. **学区改革政策**：调整学区划分和入学规则
3. **住房政策**：影响学区房价和可负担性
4. **教师流动政策**：促进优质师资向薄弱学校流动

### 政策效果传导机制
- **直接效果**：政策直接改变学校质量参数
- **市场效果**：通过房价变化影响家庭选择
- **行为效果**：改变家庭的教育投资和迁移行为
- **长期效果**：通过代际传递影响社会流动性

## 数据输出

系统生成丰富的分析数据：
- 学校质量分布的时间序列
- 学生成就的分层统计
- 居住迁移的空间模式
- 政策效果的量化评估
- 教育公平性的多维指标

这些数据支持政策制定者深入理解教育政策的复杂影响，为优化教育资源配置提供科学依据。
